## 1. 基础设施（已完成验证，可直接复跑）

```cmd
docker compose up -d                # postgres->5433, redis->6379
pip install -e ".[dev,pg]"
python -m iris.cli db init          # 默认 SQLite
:: PG 模式:
set IRIS_DATABASE_URL=postgresql+psycopg://iris:iris@localhost:5433/iris
python -m iris.cli db init && python -m iris.cli db check
```

## 2. 语料下载（可在 Windows 本机执行）

```cmd
python -m iris.cli corpus list
python -m iris.cli corpus download                 :: 只下 confirmed（6 款）
python -m iris.cli corpus download --include-pending  :: 尝试厂商直链（预期部分 404）
```

说明：
- GitHub 链接自动走 `IRIS_DOWNLOAD_MIRROR`（默认 gh-proxy.com，可用环境变量覆盖）；
- 下载后逐个注册入库并验证架构识别：
```cmd
python -m iris.cli extract add iris-home\corpus\openwrt-24.10.0-ath79-generic-tplink_archer-c7-v2-squashfs-factory.bin --brand TP-Link --product ArcherC7v2
```
注意：`extract add` 目前面向 tar.gz rootfs 包；OpenWrt 的 factory `.bin` 是原始固件（rootfs_extracted=false 属预期），binwalk 解包在 M1 接入 unblob 后补全；
- camera-slot-1 需人工获取（厂商门户或硬件侧），获取后替换 URL 并改 status=confirmed。

## 3. FirmAE 基线仿真（需 Linux / WSL2）

FirmAE 仅支持 Ubuntu 20.04；两条路径：

**路径 A（推荐）：WSL2 Ubuntu 20.04**
```bash
# WSL2 内
git clone --recursive https://gh-proxy.com/https://github.com/pr0v3rbs/FirmAE.git
cd FirmAE && ./download.sh && ./install.sh && ./init.sh
# 逐款验证（把 Windows 侧 iris-home/corpus 下固件复制进 WSL 或直接 wget）
sudo ./run.sh -c dlink DIR-868L_fw_revB_2-05b02_eu_multi_20161117.zip
```
产出读取：`scratch/<IID>/result`（true/false）、`web`、`ping`、`qemu.initial.serial.log`（失败归因用）。

**路径 B：Docker Desktop 模式**（FirmAE 官方 `docker-init.sh` + `docker-helper.py -ec`）。
注意 privileged 容器 + /dev/net/tun 依赖，Docker Desktop WSL2 后端需确认 tun 可用；失败退回路径 A。

**批量跑法**：`docker-helper.py -ec brand.list` 支持清单文件；或循环 `run.sh -c`。每款固件最长 2×TIMEOUT（约 12 分钟）。

## 4. baseline 记录与失败归因（输出物）

对 10 款固件，每款记录一行到 `docs/eval-log.md`（新建）：

| 固件 | arch 识别 | rootfs 提取 | FirmAE result | network_type | 失败阶段 | 关键日志指纹 |
|---|---|---|---|---|---|---|

失败阶段分类固定 8 类：`extraction / arch / boot / nvram / network / service / wizard / verify`（与 IRIS failure_profile.stage 一致）。
这些记录将直接喂给 M2 的失败画像结构与 M4 的 LLM 修复环——**观察越细，未来自动化越快**。
